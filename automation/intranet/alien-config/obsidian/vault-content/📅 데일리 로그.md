# 📅 데일리 로그

> 매일의 활동 기록. Calendar 플러그인을 켜면 우측 사이드바에서 달력으로 점프.
> [[🏠 Home]] 으로 돌아가기.

## 전체 로그 (최신순)

```dataview
TABLE weekday AS "요일", file.mtime AS "수정"
FROM "daily-logs"
WHERE type = "daily-log" OR contains(file.name, "-")
SORT file.name DESC
```

## 이번 달

```dataview
LIST
FROM "daily-logs"
WHERE startswith(file.name, dateformat(date(today), "yyyy-MM"))
SORT file.name DESC
```

> 템플릿(`_templates/daily-log`)이 자동 적용된다.
