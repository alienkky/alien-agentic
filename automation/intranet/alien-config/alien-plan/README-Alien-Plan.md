# Alien Plan

> 한 걸음 떨어져서 바라보는 일일 실행 시스템
>
> _by Alien Agentic_

---

## 이게 뭔가요

매일 머릿속이 시끄러우신가요? 할 일이 너무 많아서, 정작 **중요한 한 가지**를 놓치진 않나요?

**Alien Plan**은 그 소음 안에서 **딱 3가지 의식**만 매일 반복하는 시스템입니다.

```
1. Sweep     · 머릿속의 모든 것을 쏟아내기 (정리는 그 다음)
2. The One   · 오늘 끝내야 할 단 한 가지
3. Tiny Move · 저항 없이 시작할 수 있는 2분 행동
```

> "최악의 날에도, 한 걸음은 떼어낼 수 있다. 그게 전부다."

---

## 왜 만들었나요

복잡한 GTD, 강박적인 시간 관리, 6개월짜리 OKR — 모두 작동합니다. **에너지가 충분할 때만요.**

하지만 1인 운영자, 소규모 팀, 또는 번아웃 사이클에 빠진 사람에게는 **더 작은 단위**가 필요합니다. 매일 5분, 주 1회 15분. 그게 전부.

**Alien Plan**은 그 최소 단위입니다.

---

## 시작하기 (3단계)

### 1. 파일 열기

`alien-plan.html` 파일을 **더블클릭**하거나, 브라우저(Chrome·Safari·Edge 무엇이든)에 드래그하세요.

설치 없음. 회원가입 없음. 서버 없음. **그냥 열기만 하면 됩니다.**

### 2. 즐겨찾기 추가

매일 열어야 하니까, 브라우저 즐겨찾기에 추가하세요.

- Chrome/Edge: `Ctrl+D` (또는 `Cmd+D`)
- Safari: 책갈피 → 책갈피 추가

### 3. 매일 아침 5분

```
☕ 커피 마시면서…
   1. Sweep 영역에 머릿속을 다 적기
   2. The One 1개 선택 — "오늘 이것만 끝내면 잘했다"
   3. Tiny Move 1개 선택 — "지금 2분이면 할 수 있는 것"
```

저녁에 다시 열어서 체크 박스를 확인하세요. 끝.

## 4개 페이지

### ☀ Today · 오늘의 한 걸음

매일 사용하는 메인 페이지. Sweep · The One · Tiny Move 3가지 의식을 여기서.

### ✓ Tasks · Sprint Board

The One 외의 태스크들을 4개 칸반에 분류:

| Sprint | 의미 | 예시 |
|---|---|---|
| **Sprint 1 · 긴급** | 지금 당장 처리해야 할 위기 | 클라이언트 항의, 시스템 다운 |
| **Sprint 2 · 마감** | 데드라인이 명확한 것 | 제안서 마감, 미팅 자료 |
| **Sprint 3 · 운영** | 매주 반복되는 운영 업무 | 세금, 회계, 메일 답신 |
| **Sprint 4 · 창작** | 깊은 사고가 필요한 것 | 콘텐츠 제작, 전략 기획 |

**자동 기능:**
- 15분 이하 태스크 = **Quick Task** (자동 노랑 테두리)
- 마감일이 지난/오늘/내일인 태스크 = **자동 라벨** 표시

### ↻ Reflect · 주간 회고 (매주 1회 · 15분)

지난 주의 데이터를 자동 분석:

- **Step 1 (1분)** — 우선순위 분포 자동 산출 + 진단 코멘트
- **Step 2 (5분)** — 놓친 태스크 재배치 or Skip
- **Step 3 (5분)** — The One · Tiny Move 일관성 점검

### ↗ Trace · 자취 추적

이번 달 캘린더에 매일의 완료 상태가 시각화됩니다. 연속 일수(streak)도.

> **이 페이지가 가장 중요할 수도 있습니다.** 진척은 바쁠 때 가장 놓치기 쉽거든요.

## 데이터는 어디에 저장되나요

**당신의 브라우저 안에만** (`localStorage`).

- ✅ 서버로 안 보냄
- ✅ 외부 추적 없음
- ✅ 인터넷 없어도 작동
- ⚠️ 브라우저 데이터를 삭제하면 함께 사라집니다

### 백업 / 복원 / 이전

페이지 맨 아래의 버튼 활용:

| 버튼 | 무엇 |
|---|---|
| **백업 내보내기** | 전체 데이터를 JSON 파일로 저장 |
| **백업 가져오기** | JSON 파일에서 복원 (예: 다른 컴퓨터로 옮길 때) |
| **전체 초기화** | 모든 데이터 삭제 |

**권장:** 주 1회 (Reflect 시간에) 백업 내보내기 → Dropbox/Drive에 저장.

## 자주 묻는 질문

### Q. 모바일에서도 되나요?
A. 됩니다. 단, 매일 쓰려면 데스크탑이 더 편합니다. 모바일은 보조 (Tiny Move 체크 등).

### Q. 다른 컴퓨터로 옮기려면?
A. `백업 내보내기` → 새 컴퓨터에서 HTML 열기 → `백업 가져오기`.

### Q. 팀에서 공유하려면?
A. 이 버전은 1인용입니다. 팀 협업이 필요하면 **Alien Agentic 컨설팅 패키지**로 문의주세요 — 실시간 협업 버전으로 확장 가능합니다.

### Q. 디자인을 우리 브랜드 색으로 바꿀 수 있나요?
A. HTML 파일 상단 `:root { --cream: ... }` 부분을 수정하면 됩니다. (또는 컨설팅 패키지로 요청 가능)

## Alien Agentic 컨설팅과의 연결

이 도구는 **AA 컨설팅의 일부**로 작동합니다.

```
AA 6단계 협업 프로세스
  Step 0 · 진단      ← 클라이언트의 현재 시스템 분석
  Step 1 · 설계      ← Why-How-What 정렬
  Step 2 · 도입      ← 🟢 Alien Plan 도입 (여기)
  Step 3 · 운영      ← 매일 사용 + 주간 회고
  Step 4 · 측정      ← Trace 데이터로 성과 측정
  Step 5 · 확장      ← AI 에이전트 연동, 팀 확장
```

**Step 2~4가 이 도구가 작동하는 구간입니다.**

확장 옵션:
- Claude API로 Sweep 자동 분석 + The One 추천
- 팀 협업 (실시간 sync)
- 모바일 PWA 버전
- 자체 브랜드·도메인 적용
