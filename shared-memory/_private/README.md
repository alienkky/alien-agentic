# `shared-memory/_private/` — 외계인 출입금지 구역

> 이 파일(README.md)만 git 추적된다. 같은 폴더 내 **다른 모든 파일은 .gitignore 로 격리**된다.
> 이 README 는 *경계 안내문* 이지 색인이 아니다. 안의 파일 목록·요약·해시 등 어떤 메타데이터도 여기에 적지 않는다.

[CONSTITUTION.md](../../CONSTITUTION.md) §VIII 의 시간 신성화 원칙을 파일시스템 경계로 옮긴 것.

## 2. 절대 규칙 — 에이전트 27명 전원에게

### 2.1 READ 금지
- 이 폴더 안의 *어떤 파일도* 읽지 않는다.
- `cat`, `Read`, `Grep`, `Glob` 등 어떤 도구로도 본문 접근 금지.
- 폴더명·README 가 보이는 것까지는 OK. *내용을 열어보는 순간이 위반*.

### 2.2 WRITE 금지
- 이 폴더 안에 *어떤 파일도* 생성·수정·삭제하지 않는다.
- 후보 파일이 보여도 직접 `git mv` 하지 않는다. **이동은 기영님이 수행한다.**
- 에이전트는 *후보 제안* 만 가능 — 외부 경로(`shared-memory/context/private-domain-candidates.md` 등) 에 별도로 남긴다.

### 2.3 LIST 제한
- 폴더 *목록 조회* 자체는 보안 위반이 아니지만, 결과를 산출물·로그·메시지에 *복사하지 않는다*.
- 파일명 자체에 민감 정보가 들어가 있을 수 있다 (예: `한혜성_2026Q1_상담노트.md`).

### 2.4 외부 싱크 금지
- 어떤 MCP / 자동화 / 백업 스크립트도 이 폴더를 *외부로 전송하지 않는다*.
- Obsidian Vault sync, GitHub backup, Google Drive backup 등 모든 동기화 대상에서 제외.
- *로컬 디스크에만 존재*. 클라우드 / remote / 외부 LLM context 어느 쪽으로도 빠져나가지 않는다.

## 3. 위반 감지 시 — 에이전트의 셀프 보고

만약 다음 중 하나라도 발생하면 *즉시 호출 중단* 후 기영님께 보고:

- 다른 에이전트가 이 폴더를 읽으려 한 흔적 (메시지 / decisions / mistakes 어디든)
- 외부 도구가 이 경로에 접근한 로그
- 클라이언트 산출물 / 외부 콘텐츠 초안에 이 폴더에서 유래한 것으로 의심되는 문장
- 본인이 *실수로* 이 폴더를 열었음을 깨달은 순간

**위반은 처벌이 아니라 학습 자산이다.** 침묵하지 말고 [shared-memory/agents/<자신>/mistakes.md](../agents/) 에 사실 그대로 기록한다.
