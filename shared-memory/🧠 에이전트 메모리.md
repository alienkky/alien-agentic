# 🧠 에이전트 메모리

> 27명 외계 동료가 직접 쓴 기억. 각자 4파일 — work·learnings·decisions·mistakes.
> [[🏠 Home]] 으로 돌아가기.

## 📊 27명 메모리 현황

```dataview
TABLE
  length(filter(file.tasks, (t) => !t.completed)) AS "열린 작업"
FROM "agents"
WHERE file.name != "README" AND file.name != "_template"
GROUP BY file.folder AS "에이전트"
SORT file.folder ASC
```
