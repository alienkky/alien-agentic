# 💡 인사이트

> 주간·월간 통찰 + 실패 케이스 스터디. 1년 후 우리의 진입장벽.
> [[🏠 Home]] 으로 돌아가기.

## 전체 인사이트

```dataview
TABLE file.mtime AS "수정", status AS "상태"
FROM "insights"
SORT file.name DESC
```

## 메타 — 실패 케이스 (가장 비싼 자산)

```dataview
LIST
FROM "meta" OR "insights"
WHERE contains(file.name, "drift") OR contains(tags, "mistake") OR contains(tags, "failure")
SORT file.mtime DESC
```
