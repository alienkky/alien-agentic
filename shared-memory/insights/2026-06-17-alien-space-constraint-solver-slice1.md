### B. 2D 구속 솔버 커널 — `kernel/constraintSolver.ts` (자체, 외부 의존 0)
- 점=자유변수, 구속=잔차 함수, **Levenberg–Marquardt** 비선형 최소제곱으로 동시 해결.
- 구속 8종: coincident · horizontal · vertical · distance · fixX · fixY · parallel · perpendicular.
- 고정점(`fixed`)은 변수에서 제외 → 드래그로 잡은 점/원점은 안 움직임.
- 야코비 수치미분 + 자체 가우스 소거(부분 피벗) 선형 솔버. 순수 함수(입력 불변).

## 교훈 (가장 비싼 자산)
**LM 감쇠는 가법이라야 한다.** 처음 곱셈 감쇠 `A_aa = JᵀJ_aa·(1+λ)` 로 짰더니, *구속이 안 걸린 자유변수*(예: distance 만 있는 점의 접선 방향)는 그래디언트가 0 → 대각이 0 → `1+λ` 곱해도 0 → **특이행렬** → 선형 솔버 null → 한 발도 못 감. 6개 테스트가 동시에 잡아줌.
수정: `A_aa = JᵀJ_aa + λ(1+JᵀJ_aa)`. 0 대각이 λ 로 떠서 비특이가 되고, 구속 없는 변수는 Δ≈0 으로 제자리. (planegcs 도 내부적으로 같은 함정을 LM 으로 우회한다 — 자체 구현하며 그 이유를 몸으로 알게 됨 = 자산화의 핵심.)
