# 그리기-시점 스냅 (끝점/중점/축) — 솔버 없이 먼저 가능한 절반

## 배경
"다음 진행" 지시. 구속 에픽의 첫 슬라이스로, **반복(iterative) 솔버가 필요 없는 기하 흡착**만 분리해 구현.
영상의 "보라색 수직 연장선", "끝점/중점에 붙는 스냅"은 솔버가 아니라 그리기 순간의 좌표 흡착이다 — 같은 입력 → 같은 출력.

## 한 일 (전부 결정론적, 순수 함수 토대)
- `kernel/sketchSnap.ts` — 순수 모듈:
  - `collectSnapPoints(strokes)` 끝점+중점 후보 (원/타원 등 다점 곡선은 노이즈로 제외, 8점 초과 스킵)
  - `nearestSnapPoint(p, cands, tol)` tol 이내 최근접 (끝점이 중점보다 우선)
  - `axisSnap(anchor, p, tolDeg)` 이전 점 기준 수평/수직 흡착
  - `resolveSnap(raw, opts)` 우선순위 = 점 스냅 > 축 스냅 > (호출자) 격자 폴백
- store: `sketchSnapHint` 상태 + `computeSketchSnap(raw, st)` 헬퍼. `sketchClickPoint`/`sketchDragMove`(점 도구)에 적용.
  스냅 토글 게이팅(`snap.sketchPoint`=끝점/중점, `snap.sketchLine`=축). 확정·취소·도구전환·평면선택에서 힌트 정리.
- `SketchLayer.SnapHintView` — 끝점=주황 구, 중점=청록 옥타헤드론, 축=보라 점선 가이드 + 마커. `snap.snapHint` 표시 토글 존중.

## 교훈

### 1. "스냅"과 "구속"은 다르다 — 스냅 먼저, 구속은 나중
- 스냅 = 그리는 *순간* 좌표를 흡착(결정론·즉시). 구속 = 도형 *관계*를 지속적으로 만족시키는 방정식(반복 솔버).
  영상은 둘을 한 흐름처럼 보여주지만, 스냅만으로 사용자 체감의 80%(끝점에 딱 붙음·수직선 가이드)가 나온다.
  솔버(planegcs) 없이 이걸 먼저 줘서 손맛을 확보하고, 진짜 구속 지속성은 다음 슬라이스로 미룬다. **체감 우선순위로 자른다.**

### 2. 스냅 우선순위는 한 곳에서 — point > axis > grid
- 세 흡착이 동시에 후보일 때 순서가 흔들리면 커서가 튄다. `resolveSnap` 한 함수에 우선순위를 박아 단일 출처로.
  격자 스냅은 의도적으로 *호출자(store)* 가 폴백으로 처리 — 순수 모듈은 기하 흡착만, 격자 간격(SNAP 상수)은 store 도메인.

### 3. 격자 스냅이 끝점 스냅을 *가린다* — 테스트는 격자를 꺼고 검증
- 끝점이 격자점(예: 4.0)이면 격자 반올림과 끝점 스냅 결과가 같아 구분 불가. 테스트는 **격자 off + 비격자 좌표(4.3)** 로
  끝점 스냅만 단독 검증. 실사용에선 둘 다 켜도 point 우선이라 자연스럽게 끝점이 이긴다.

### 4. 스냅 마커는 평면 정렬을 신경 쓸 필요 없는 형상으로
- `<Html>`/박스는 평면 기울기에 맞춰 회전시켜야 보기 좋지만, 구·옥타헤드론은 방향 무관이라 어느 스케치 평면에서도 깔끔.
  축 가이드는 평면 local (u,v) 로 ±1000 길게 그어 `planeToWorld` 변환 → 평면 위에 정확히 눕는다.

## 남은 것 — 진짜 구속 솔버 (다음 슬라이스)
- 자동 구속 *지속성*: 수평/수직/평행/수직(perp)/접선/일치/동심 — 도형을 끌면 관계가 유지되도록.
- planegcs(WASM) 도입 vs 자체 2D 구속 솔버 — 기영님 결정 대기. 전자=빠름, 후자=우리 자산.
- 박스 선택(좌→우 포함 / 우→좌 교차)·구성선·항상 구속 표시·구속 핫키(Shift+P)·3D 뷰 큐브.
