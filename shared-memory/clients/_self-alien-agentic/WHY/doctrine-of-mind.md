## 3. 십계 빈도 — 어느 줄이 회사를 가장 무겁게 짊어지는가

| 십계 | 빈도 | 무게 |
|---|---|---|
| 연기 (緣起) | 6명 | 가장 무거움 — 회사 전체가 *사슬을 본다*. 매듭의 자리. |
| 일체유심조 (一切唯心造) | 4명 | WHY·HOW·WHAT 모두 마음의 외화. |
| 제행무상 (諸行無常) | 4명 | 미래·트렌드·콘텐츠 — 변화 직시. |
| 수심 (守心) | 3명 | 데이터·지식·관계 보전. |
| 반조자심 (返照自心) | 2명 | 자기 자신을 보기 — 회사 사상의 핵. |
| 적정중생혜 (寂靜衆生慧) | 2명 | 페인·결함은 고요에서 보임. |
| 탐심시고근 (貪心是苦根) | 2명 | 영업·재무 — 탐욕 거절. |
| 당하즉시 (當下卽是) | 2명 | KPI·자동화 — 지금. |
| 진화선소심 (瞋火先燒心) | 1명 | brand-keeper — 분노로 쓴 글 차단. |
| 항복자심 (降伏自心) | 1명 | subagent-builder — 자기 한계 이김. |

> 진단: 회사의 일은 *사슬을 보고 (연기) 마음으로 짓고 (일체유심조) 변화를 직시하면서 (제행무상) 매듭을 풀어나가는 일* 이다. 십계가 회사의 일을 거꾸로 비춰주는 거울이 된다.
