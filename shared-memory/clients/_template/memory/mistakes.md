## 작동 원칙
- 실수는 *가장 비싼 자산*. 절대 지우지 않는다.
- *원인을 사람*으로 환원하지 않는다. 시스템의 매듭으로.
- 같은 실수가 *2번 반복*되면 → `meta/failures/` 로 elevation + 헌법 보정 검토.
- 클라이언트의 가족·개인 정보가 들어가면 *즉시 익명화*.
