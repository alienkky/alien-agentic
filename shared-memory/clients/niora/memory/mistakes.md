# 니오라 프로젝트 실수와 재발 방지

## 2026-05-27 - 산출물이 shared-memory에 기록되지 않음

- ALI-30~ALI-34 WHY 세션 산출물이 이슈 댓글에만 존재했고, `shared-memory/clients/niora/`에는 기록되지 않았다.
- 결과적으로 다른 에이전트가 니오라 맥락을 이어받기 어려운 상태가 됐다.

## 재발 방지

- 클라이언트 프로젝트 산출물은 이슈 댓글 작성 후 반드시 `shared-memory/clients/{client}/{stage}/`에 같은 내용을 저장한다.
- 산출물 파일에는 원본 이슈 ID, 댓글 ID, 작성일을 메타데이터로 남긴다.
- 후속 보정 댓글이 중요한 방향 변경을 포함하면 원 산출물 파일에 `후속 보정` 섹션으로 함께 보존한다.
