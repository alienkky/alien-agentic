이 에이전트가 *새로 발견한 패턴·통찰*을 호출별로 append.

## 표준 항목

```
### 2026-MM-DD HH:MM · {slug}
**패턴**: {한 줄 요약}

**상황**: {어느 호출/어떤 클라이언트/어떤 자료에서 보였나}

**가설**: {왜 이 패턴이 작동했나}

**적용**: {다음 호출에서 어떻게 활용할까}
```

(여기 아래로 append)

### 2026-05-16 04:07 · aa-squad-register
**패턴**: 사람·기계가 함께 읽는 등록부는 *진실원 한 곳 + 헌장 한 곳* 으로 분리해야 한다.

**상황**: 스쿼드를 `aa` CLI 1급 시민으로 올리며 `squad.toml`(머신 판독) + `README.md`(사람용 헌장) 두 파일을 같은 폴더에 둠. 둘이 어긋나면 `squad.toml` 이 진실.

**가설**: 한 파일에 둘을 섞으면 한쪽이 거짓말을 시작한다. 사람을 위한 표현은 *부드러워야* 하고, 기계가 읽는 자리는 *엄격해야* 한다. 서로의 적합 형식이 다르다.

**적용**: 앞으로 다른 1급 시민(예: 클라이언트 등록부, 자체 자기진단)도 같은 패턴 — `*.toml` + `README.md` 페어. 진실원은 `tomllib` 스키마로 파싱 가능해야 함.
