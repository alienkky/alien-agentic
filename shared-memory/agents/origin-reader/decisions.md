### 2026-05-16 04:07 · aa-squad-register
**결정**: `aa squad` 서브앱에 `list/show/register` 3개 명령만 넣고, `call/activate` 는 **의도적으로 추가하지 않음**.

**대안**:
- (A) `aa squad call <slug>` — 스쿼드 전원 일괄 호출
- (B) `aa squad activate <slug>` — 상태를 FORMED → ACTIVE 로 자동 승격
- (C) `list/show/register` 만 (선택)

**선택 이유**:
- `list/show` 는 *조회* — 토큰 0
- `register` 는 *스캐폴딩* — 토큰 0
- 등록·조회까지가 CLI 의 자리. 그 너머는 사람의 결정.

**기각 이유**:
- (A) 헌법 "동시 호출 최대 5명" 위반. brand-system 만 해도 13명 — 한 줄로 토큰 폭주.
- (B) 가동 결정은 기영님의 자리. CLI 가 *자동 승격*하면 페이즈 게이트가 무력화된다.

**되돌릴 조건**:
- 페이즈별 부분 호출(`aa squad call <slug> --phase 1` 같은)이 명시적으로 요청되면 재검토.
- 가동/해체가 *루틴*이 될 만큼 스쿼드가 많아지면 `activate/disband` 도입 검토.

## 작동 원칙
- 결정은 *기록될 때 진짜 결정*이 된다. 머릿속에만 있는 건 의도.
- *되돌릴 조건*을 못 적는 결정은 *너무 큰 결정*. 더 작게 쪼개기.
