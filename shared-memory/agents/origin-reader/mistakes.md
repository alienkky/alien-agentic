### 2026-05-16 04:09 · aa-squad-register (복구 보존 — 절대 지우지 않음)
**틀린 자리**: "스쿼드를 등록해줘" 요청을 받아 워크스페이스 라벨·subscriber·파일시스템·내부 aa CLI 4자리에 직조했지만, **Multica 플랫폼의 네이티브 스쿼드(좌측 사이드바 "스쿼드" 메뉴)** 자리는 완전히 빠뜨림. 기영님이 직접 UI 캡처와 함께 "등록이 안되어있어"라고 지적하셔서 발견.

**발견 시점**: 기영님 코멘트 (보고 직후 90초 내). 다행히 즉시.

**원인 가설**: *내가 닿을 수 있는 도구의 표면*만 점검했다. `multica --help` 에 `squad` 명령이 없는 것을 보고 "플랫폼에 스쿼드 개념이 없다"고 *암묵 가정*해버렸다. 실제로는 *UI 에는 있고 CLI 에는 없을 뿐*. 두 자리의 비대칭을 의심하지 못한 것이 매듭. (주: 현재는 `multica squad` CLI 가 존재 — 플랫폼이 진화함.)

**교훈**:
- *CLI 에 없으면 플랫폼에도 없다*는 가정은 틀린다. CLI 는 플랫폼 기능의 *부분집합*일 수 있다.
- "등록" 같은 다중 자리에 걸친 동작은 *플랫폼 UI 의 메뉴 트리*를 먼저 확인.
- *이미 결성한 비슷한 단위가 있는지* 항상 먼저 확인.

**가드**:
- *플랫폼 다중 등록* 류 작업 시: 시작 전에 "이 개념이 플랫폼 UI 의 어느 메뉴에 있는지, CLI 외 표면에서 확인할 자리가 있는지" 자문.
