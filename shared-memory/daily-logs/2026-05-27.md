## 교훈

1. **drift 의 두 얼굴**: build override 누락(이미지 drift) + 부분 머지(로컬 변경 충돌). 둘 다 *부분 체크아웃* 패턴으로 풀림.
2. **PS 5.1 인코딩의 함정**: BOM 없는 UTF-8 = CP1252 로 읽힘. 다중바이트 시퀀스의 0x92/0x94 가 curly quote 로 오해돼 string terminator 가 깨짐. **모든 한국어 PS 파일에 BOM 박는 게 표준**.
3. **stderr ≠ error**: Caddy·tailscale 같은 native 명령은 정상 동작 시에도 stderr 로 로그를 떨군다. `$ErrorActionPreference=Stop` 과 만나면 abort. **EAP=Continue + Out-String + $LASTEXITCODE 패턴** 이 안전.
4. **마일스톤별 push**: 5~6시간 작업도 30~120분 마일스톤 4개로 끊으면 중간에 검증 가능. 사용자 작업 컨디션 유지에도 좋음.
