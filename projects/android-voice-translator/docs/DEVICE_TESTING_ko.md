# 실기기 테스트 가이드 — 실시간 일↔영 음성 번역

이 문서는 앱을 폰에 올려 **실제로 말해보며 검증**하는 절차입니다. 인식 품질의 가장 큰 변수는 **폰에 깔린 음성 언어팩**이므로, 그 설치부터 다룹니다.

---

## 0. 준비물
- Android 7.0(API 24) 이상 실기기 1대 (에뮬레이터는 마이크·음성인식이 불안정 → **실기기 권장**)
- USB 케이블 + 개발자 옵션의 **USB 디버깅** 켜기
- (선택) 클라우드 Whisper 테스트용 API 키

---

## 1. 빌드 & 설치

### Android Studio
1. `projects/android-voice-translator` 를 **Open**.
2. Gradle 동기화 완료 후, 상단에서 연결된 기기 선택 → **Run ▶**.

### 커맨드라인
```bash
cd projects/android-voice-translator
gradle wrapper                 # 최초 1회 (gradlew + wrapper jar 생성)
./gradlew installDebug         # 연결된 기기에 설치
```

---

## 2. 오프라인 음성 언어팩 설치 (인식 품질의 핵심)

온디바이스 엔진은 폰의 Google 음성 인식기를 씁니다. **일본어·영어 오프라인 팩**이 깔려 있어야 오프라인에서 정확히 인식합니다.

### 삼성/픽셀 등 대부분
1. **설정 → 일반(시스템) → 언어 및 입력**
2. **음성 입력** 또는 **Google 음성 인식** 진입
3. **오프라인 음성 인식 / Offline speech recognition** 메뉴
4. **언어 다운로드**에서 **English**, **日本語(Japanese)** 각각 다운로드
5. (픽셀) 설정 → 시스템 → 키보드 → 음성 입력 → 오프라인 인식 언어 관리

> 메뉴 명칭은 제조사·OS 버전마다 다릅니다. "오프라인 음성", "Offline speech", "voice download" 로 설정 검색하면 빠릅니다.

### 확인
- Gboard 마이크로 일본어/영어를 말해 텍스트가 바로 뜨면 OK.

---

## 3. 첫 실행 체크리스트
1. 앱 실행 → **마이크 권한 허용**.
2. 상태표시줄이 "번역 모델 준비 중…" → "준비됨" 으로 바뀌는지 확인 (ML Kit 일↔영 모델 1회 다운로드, **Wi-Fi 권장**).
3. 우상단 `🎙 日本語 / English` 로 **말할 언어**를 맞춤 (번역 방향은 자동이지만 STT 정확도는 이 힌트에 좌우됨).

---

## 4. 시나리오별 검증

| # | 말하기 | 기대 결과 |
|---|---|---|
| 1 | 듣기=日本語 로 "おはようございます" | 위: 일본어 원문 / 아래: "Good morning" / 배지 `JA → EN` |
| 2 | 듣기=English 로 "Where is the station?" | 아래: "駅はどこですか" / 배지 `EN → JA` |
| 3 | 말하다 0.8초 쉬고 다시 말하기 | 문장 단위로 끊겨 연속 번역 |
| 4 | 비행기모드(오프라인) + 온디바이스 엔진 | 모델 다운로드 후라면 정상 동작 |
| 5 | 설정에서 **TTS 켜고** 말하기 | 번역문이 음성으로 재생 |
| 6 | **⧉ 오버레이** → 권한 허용 → 홈으로 나가기 | 다른 앱 위에 자막 떠 있고 드래그로 이동 |
| 7 | 오버레이 우상단 **✕ 닫기** 탭 (또는 앱에서 **⧉ 오버레이 끄기**) | 자막이 사라지고 서비스 종료 |

---

## 5. 클라우드 Whisper(고정밀) 테스트
1. **⚙ 설정 → "클라우드 Whisper 사용" 켜기**.
2. **Base URL**: 기본 `https://api.openai.com/v1` (호환 서버면 그 주소).
3. **API Key** 입력, **모델**은 `whisper-1` (또는 서버가 제공하는 모델명).
4. 저장 후 메인 화면 엔진 라벨이 "클라우드 Whisper" 로 바뀌는지 확인.
5. 말하면 발화가 끝날 때(약 0.8초 침묵) 서버로 전송되어 더 정확한 전사가 옵니다.

> 클라우드 모드는 발화 단위 전송이라 온디바이스보다 약간의 지연이 있습니다. 정확도↔지연 트레이드오프.

---

## 6. 자주 막히는 곳
| 증상 | 원인 / 해결 |
|---|---|
| 인식이 전혀 안 됨 | 오프라인 언어팩 미설치 → 2장. 또는 마이크 권한 거부 |
| "음성 인식을 사용할 수 없습니다" | 기기에 음성 인식기 없음 → 클라우드 Whisper 모드 사용 |
| 번역이 안 나옴 | ML Kit 모델 다운로드 실패 → Wi-Fi 연결 후 앱 재시작 |
| 오버레이가 안 뜸 | 설정에서 "다른 앱 위에 표시" 권한 허용 필요 |
| 방향이 거꾸로 | 짧은 단어는 언어 식별이 흔들림 → 한 문장으로 말하기 |
| 클라우드 401/403 | API Key·Base URL 확인 |
