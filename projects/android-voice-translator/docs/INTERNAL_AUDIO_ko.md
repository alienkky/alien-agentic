# 폰 내부 소리 자막이 안 될 때 (갤럭시/One UI)

내부 소리 캡처(🔊 버튼)는 폰에서 *재생되는* 오디오를 가져와 번역합니다. 안 잡힐 때 아래 순서로 점검하세요.

## 1. 클라우드 Whisper가 켜져 있어야 함 (필수)
내부 소리는 **온디바이스 인식기를 못 씁니다.** 반드시 클라우드 전사가 필요해요.
- **⚙ 설정 → "클라우드 Whisper 사용" 켜기**
- **API Key** 입력, **Base URL** 확인(OpenAI면 `https://api.openai.com/v1`), 모델 `gpt-4o-mini-transcribe` 또는 `whisper-1`
- 키가 없으면 🔊 버튼이 "클라우드 Whisper(API 키)가 필요합니다" 토스트를 띄우고 설정으로 보냅니다.

## 2. 권한 두 개
- **다른 앱 위에 표시(오버레이)** 권한 — 자막을 띄우려면 필요
- **화면 캡처 동의** — 🔊 누르면 "녹화/전송을 시작할까요?" 창이 뜹니다 → **시작/허용**
  - 이 동의는 **앱을 켤 때마다** 다시 떠요(안드로이드 정책). 매번 허용해 주세요.

## 3. 화면에 뜨는 메시지로 원인 파악
이번 버전부터 **오버레이에 원인이 표시**됩니다.
| 화면 표시 | 의미 / 해결 |
|---|---|
| "내부 소리 듣는 중…" 만 계속 | 소리가 안 잡힘 → 4번(차단 앱) 또는 볼륨 확인 |
| "전사 실패: HTTP 401/403" | API 키가 틀림 → 설정에서 키 다시 입력 |
| "전사 실패: HTTP 429" | API 사용량 한도/요금 → OpenAI 결제·한도 확인 |
| "번역 오류: …" | 번역 모델 다운로드 문제 → Wi-Fi 후 재시도 |
| 일본어 원문은 뜨는데 번역만 안 됨 | 번역 모델 받는 중 → 잠시 대기 |

## 4. 그 앱이 캡처를 허용하는가 (가장 흔한 원인)
안드로이드는 **앱이 허용한 경우에만** 내부 소리를 캡처할 수 있습니다.
- **차단(소리 안 잡힘)**: 넷플릭스·디즈니+·왓챠 등 **DRM 영상**, 일부 음악 앱
- **대체로 허용**: 유튜브, 브라우저 재생, 갤러리 동영상, 다수 영상 앱
- **테스트 추천**: 먼저 **유튜브 일본어 영상**으로 확인하세요.

차단 앱이면 → **방법 1(스피커 → 마이크)** 로 우회:
1. 🔊 대신 일반 **⧉ 오버레이**(마이크 모드)
2. 영상은 **스피커로** 재생(이어폰 X), 볼륨 적당히
3. 우상단 듣기 언어 `🎙 日本語`

## 5. 그래도 안 되면
- 볼륨을 올리고 영상에 **실제 사람 대사**가 나오는 구간으로 테스트(효과음/음악만 있으면 전사가 비어 옵니다).
- 캡처는 약 **4초 간격**으로 전송되므로, 자막이 처음 뜨기까지 몇 초 걸립니다.
- One UI 버전(설정 → 휴대전화 정보)을 알려주시면 기기별로 더 짚어드릴 수 있어요.
